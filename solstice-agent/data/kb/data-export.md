# Exporting your data

Workspace admins can export an entire workspace from Settings → General → Export. Exports include all docs, tasks, comments, and file attachments, in your choice of JSON or CSV plus original files. Only admins can trigger a full-workspace export; individual members can export pages they own as Markdown or PDF from the page menu.

## How exports work

Export jobs run in the background and you receive an email with a download link when the archive is ready. Small workspaces finish in minutes; workspaces over 20 GB can take several hours. The download link expires after 48 hours, after which you must generate a new export.

## The Data Export API

Enterprise and Pro workspaces can automate exports through the Data Export API. Pro workspaces get 50 GB of API export volume per month included, with overage billed at $0.02 per GB. Enterprise export volume is unlimited.

## Deleting your data

Deleting a workspace starts a 30-day grace period during which an admin can restore it. After 30 days all data is permanently deleted from production systems, and from backups within a further 35 days. Enterprise customers can request accelerated deletion with written confirmation.
