# Mobile apps

Solstice for iOS and Android supports docs, tasks, notifications, and search. A few desktop features are not available on mobile: workspace analytics, admin settings, and the integrations gallery.

## Offline mode

Pages you have opened recently are available offline automatically. To pin additional pages for offline use, open the page menu and choose "Available offline". Offline edits sync when you reconnect, with the same conflict rules as the desktop app.

## Biometric lock

Enable Face ID / fingerprint lock under app Settings → Privacy. When enabled, the app locks after 60 seconds in the background. Biometric lock is a device-level setting and does not affect your other sessions.

## Notifications

Push notifications cover mentions, task assignments, and comments by default. Fine-tune per-project notification levels under app Settings → Notifications. Quiet hours configured on mobile apply only to that device.
